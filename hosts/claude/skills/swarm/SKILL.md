# SWARM for Claude Code

Preserve the assigned structural role and user instructions. CTRL coordinates; producers build; independent reviewers assess the exact artifact. Identify the objective, ownership, mutable surface, proof and acceptance route before work.

Inspect the project's `SWARM.md` and existing state before routing. The packaged `scripts/swarm_contract.py` uses the existing runtime's request Ledger; it is not the project-ticket service. Read its `--help` before use and verify compatibility with the project's runtime. Use an explicitly configured, verified SWARM ticket service if actually available.

Use only host capabilities actually available and authorized. A Claude subagent is not proof of a durable SWARM task or a Codex thread. Codex task, title, pin, goal, UI, dispatch and acceptance capabilities have no assumed Claude equivalent. Report missing capabilities and continue independent authorized work. Never fabricate identities, receipts or acceptance.

Report the changed artifact, proof actually run and unverified integration boundaries. This package does not install a SWARM MCP server or claim live ticket integration.
