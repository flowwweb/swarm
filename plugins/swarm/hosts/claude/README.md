# SWARM for Claude Code

SWARM provides a structured project workflow with explicit ownership, proof and independent review.

For a session-only local test, run `claude --plugin-dir <absolute-plugin-directory>` and invoke `/swarm:swarm`. This package includes SWARM's runtime and request Ledger contracts. It does not install a SWARM MCP server or establish shared project-ticket access, Codex task controls, dispatch or acceptance. Those capabilities require separately verified host support.
